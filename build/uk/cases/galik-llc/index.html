Переглянути джерело прикладу

Як у цьому прикладі застосовано циркулярні стратегії?

Оптимізація процесів випалювання вапна та дроблення дає змогу зменшити кількість енергії, необхідної для виробництва одиниці продукції, та скоротити частку енергетичних витрат у загальних виробничих витратах.

Опис прикладу

Galik LLC – підприємство з виробництва вапна, що постачає продукцію для металургійного сектору, – використало оцінку за методикою РЕЧВ для оптимізації роботи випалювальних печей та процесів подрібнення, зосередившись на зниженні енергетичних витрат, які становили 22% від загальної собівартості продукції. У межах РЕЧВ-оцінки програми EU4Environment, Galik визначила можливості оптимізації процесів випалювання вапна та дроблення для зменшення споживання енергії на одиницю продукції. Цей приклад демонструє, як заходи з підвищення ресурсоефективності в енергоємній важкій промисловості можуть безпосередньо сприяти підвищенню конкурентоспроможності за витратами та одночасно покращувати екологічні показники.
